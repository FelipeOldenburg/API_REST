# API de Eventos 🎉

API REST desenvolvida com Node.js e MongoDB para gerenciamento de eventos com autenticação de usuários.

##  Tecnologias utilizadas

- Node.js
- Express
- MongoDB
- Mongoose
- JWT (JSON Web Token)
- Bcrypt

---

##  Como rodar o projeto

npm install
cp .env.example .env
npm run dev

## Endpoints
POST /register
POST /login
GET /events
POST /events
PUT /events/:id
DELETE /events/:id
